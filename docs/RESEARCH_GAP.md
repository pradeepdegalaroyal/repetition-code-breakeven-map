# Research gap

**State of the art.** Sivak et al. (2023, doi:10.1038/s41586-023-05782-6) report real-time quantum error correction that extends a logical qubit's lifetime beyond the best physical component ("break-even"), and note that whether QEC can be used in practice to extend coherence was an open question. Evered et al. (2023, doi:10.1038/s41586-023-06481-y) show 99.5% parallel two-qubit gates on neutral atoms, i.e. gate error is nearing code thresholds. Burkard et al. (2023, doi:10.1103/RevModPhys.95.025003) stress that noise filtering and fidelity limits decide which platforms scale. Azuma et al. (2023, doi:10.1103/RevModPhys.95.045006) list loss and noise as the main obstacles for repeater-style memories.

**Gap.** Break-even is usually reported as a single experimental point. What an engineer needs before building a test-automation or resource-estimation workflow is the *margin*: for a given qubit T1, how long may a QEC cycle (including slow ancilla readout) be, and how bad may the syndrome-extraction gates and readout be, before encoding stops helping?

**Hypothesis (falsifiable).** For a bit-flip repetition-code memory with T1-limited idling, a d=3 code with exact space-time decoding beats the unencoded qubit (logical/physical per-cycle rate < 1) across cycle times 0.5-4 µs (T1 = 50 µs) and ancilla readout error up to 10% at gate-induced data flip 0.3%, and the break-even gate-induced flip rate is above 1%. Increasing d to 5 raises that margin. Success metric: ratio of logical to physical per-cycle flip rate, mean ± std over 4 seeds. The hypothesis fails if any grid point has ratio ≥ 1 or if the break-even gate error is ≤ 1%.

**Scale.** Phenomenological Monte Carlo on a laptop (d = 3, 5, 7, 10 rounds); it does not model coherent errors, leakage or Z errors.
